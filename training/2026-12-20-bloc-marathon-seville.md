# Bloc Marathon Séville — 20/12/2026 au 20/02/2027

Bloc marathon complet visant Séville (21/02/2027). Utiliser le template 5-phase (Récup/Base/Spécifique/Pivot/Affûtage) adapté à la durée du bloc (9+ semaines idéalement). Toutes les estimations de pace ou d'allure doivent être marquées "à confirmer" si non fixées avec l'athlète.

## Structure macro
- Récup : 1 semaine (si nécessaire selon état de l'athlète)
- Base : ~3 semaines
- Spécifique : ~4-5 semaines (avec progressions hebdo décrites ci-dessous)
- Pivot : 1 semaine (dernière grosse sortie longue)
- Affûtage : ~2 semaines

## Points clefs
- Point de départ volume : dernier hebdo réel connu (lire fichier de bloc précédent)
- Insérer un down-week tous les 3-4 semaines de construction si opportun
- Pivot = test long run marathon-pace (ou proche), dernière véritable grosse session avant taper

## Règles de sécurité
- Un flag médical/fatigue bloque toute hausse
- Si une cascade d'écarts rend impossible d'atteindre la charge planifiée, appeler `long-term-plan` pour recalculer les blocs suivants et notifier l'athlète

## Transparence
- Toute allure cible non confirmée par l'athlète doit être marquée "à confirmer" dans les séances
